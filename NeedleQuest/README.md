# 🪡 Needle Quest — مهمة الإبرة

لعبة موبايل 3D كاملة مبنية بمحرك **Godot 4.3+**: ابحث عن الإبرة المخفية داخل كومة قش ضخمة متعددة الطبقات!

A complete 3D mobile game built with **Godot 4.3+**: find the needle hidden inside a huge, multi-layered 3D haystack!

---

## 🚀 التشغيل / How to run

1. حمّل **Godot 4.3 أو أحدث** (النسخة العادية، ليست .NET) — على الحاسوب أو **محرر Godot لأندرويد** من المتجر.
2. افتح Godot → **Import** → اختر ملف `project.godot` داخل مجلد `NeedleQuest`.
3. انتظر الاستيراد الأول (ثوانٍ) ثم اضغط ▶ للتشغيل.
4. للتصدير إلى APK: نزّل *Android Export Templates* من داخل المحرر (Editor → Manage Export Templates) ثم Project → Export → Android (الإعداد جاهز في `export_presets.cfg`).

> اللعبة تعمل أيضًا على الحاسوب للتجربة (الفأرة تحاكي اللمس، والعجلة للتقريب).

## 🎮 اللعب / Gameplay

- **اضغط** على القش لإزالته طبقة فوق طبقة.
- **اسحب** بإصبع لتدوير الكاميرا، **قرّب بإصبعين** (Pinch) أو حرّك بإصبعين للتنقل.
- اعثر على **الإبرة** المخفية في الأعماق — ستشعر بقربها عبر الوميض والأصوات!
- اجمع العناصر المخفية (عملات، جواهر، كنوز، إبر ذهبية وأسطورية...).
- حرّك الصناديق والبراميل، واكتشف المخابئ السرية.

## 🧰 الأنظمة / Systems

| النظام | الوصف |
|---|---|
| مولّد المراحل | Procedural + Seeded، مئات المراحل بلا نهاية، منع الحالات المستحيلة |
| الأدوات (7) | اليد، المكنسة، المكبر، المروحة، الحفّار، المغناطيس، الكاشف |
| الترقيات (7) | شجرة ترقيات بتأثير حقيقي في اللعب |
| التلميحات | 3 مستويات تدريجية لا تكشف المكان مباشرة |
| النجوم | تقييم 1–3 نجوم حسب الوقت والتلميحات |
| التحدي اليومي | Seed من التاريخ — نفس المرحلة للجميع كل يوم |
| المجموعة | 15 عنصرًا بندرات من شائع إلى خرافي |
| الإنجازات | 17 إنجازًا بمكافآت |
| الحفظ | JSON محلي آمن، قابل للاستبدال بـ Cloud Save |
| اللغات | العربية (RTL) والإنجليزية، تبديل فوري |
| الجودة | Low/Medium/High/Ultra تؤثر فعليًا على الظلال/MSAA/الجسيمات |
| الإعلانات | طبقة AdsManager معزولة (محاكاة الآن، جاهزة لأي SDK) |

## ⚡ الأداء / Performance

- القش يُرسم عبر **MultiMesh واحد لكل طبقة** — آلاف العيدان بعدد Draw Calls لا يتجاوز أصابع اليد.
- **لا فيزياء لكل قشة**: الالتقاط عبر Ray–Sphere تحليلي، والحركة عبر تحريك Transforms فقط.
- جسيمات One-shot تحرر نفسها، وأصوات من Pool ثابت.
- مستهدف 60 FPS على الأجهزة المتوسطة فما فوق.

