### المزايا
- 🌾 كومة قش 3D متعددة الطبقات مع فيزياء تفاعل محسّنة للموبايل (MultiMesh + Ray picking)
- 🎲 مولّد مراحل إجرائي Seeded — مئات المراحل، 8 بيئات، 7 مستويات صعوبة
- 🧰 7 أدوات (مكنسة، مروحة، مغناطيس، كاشف، حفّار...) + شجرة ترقيات
- 💡 تلميحات تدريجية، نجوم 1–3، تحدٍ يومي، مجموعة 15 عنصرًا، 17 إنجازًا
- 🕌 عربية (RTL) + English مع تبديل فوري
- 🔊 25 صوتًا وموسيقى أصلية مولّدة إجرائيًا — كل الأصول أصلية 100%
- 📱 Portrait 9:16، إعداد تصدير أندرويد جاهز، جودة رسومات 4 مستويات
